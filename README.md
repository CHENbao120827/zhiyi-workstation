# 智己工作站 · 个人工作台

一个 24 小时内从 0 长出来的桌面小宇宙。目标：让你每天打开电脑的第一眼，就有一个好用、好看、属于你自己的地方。

## 怎么打开（推荐）

双击桌面上的 **`启动工作台.bat`**（已放在桌面根目录，方便一眼找到）：自动启动本地后端并打开浏览器（http://localhost:8600），即可使用完整功能（含实时系统监测、一键启动本机应用、马上起飞）。数据全部保存在你自己的电脑浏览器里。

也可以直接双击 **`智己工作站\index.html`** 免启动查看（天气/新闻仍实时，系统监测与启动器会提示未连接后端）。

## 当前包含

| 文件 | 作用 |
|---|---|
| `index.html` | **单文件**个人工作台主程序（CSS/JS/9 个图标全部内联，可直接部署到任意静态托管） |
| `server.py` | 本地后端服务（Python 标准库，无需安装任何依赖）：静态托管 + 实时系统监测 API + 新闻代理 + 应用启动 |
| `启动工作台.bat` | 一键启动（位于桌面根目录，双击后自动开服务并打开浏览器） |
| `icons/` | 快捷入口原始图标（已内联进 index.html，此处为备份） |
| `路线图.html` | 24 小时打造计划可视化页 |
| `README.md` | 本说明 + 更新日志 |

> `server.js`（Node 版后端）已弃用保留——你的电脑没有 Node.js，现由 `server.py` 接管，无需安装任何东西。
